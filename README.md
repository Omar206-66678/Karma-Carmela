# مخزن الجملة — نظام إدارة مخزن سلع غذائية (PWA يعمل بدون إنترنت)

تطبيق ويب تقدمي (PWA) للموبايل: يُثبَّت على الشاشة الرئيسية، ويخزّن كل البيانات على الجهاز (IndexedDB)، ويعمل بالكامل بدون إنترنت.

## التشغيل
- محلياً: `python3 -m http.server 8000` ثم افتح `http://localhost:8000` (الـ Service Worker يحتاج http/https).
- على GitHub Pages: ارفع محتوى المجلد كما هو، افتح الرابط من الموبايل ثم "إضافة إلى الشاشة الرئيسية".
- عند تعديل أي ملف: غيّر رقم `V` في `sw.js` (مثلاً wms-v2) ليتحدّث الكاش.
- من "المزيد ← الإعدادات" يمكنك إضافة بيانات تجريبية.

## الهيكل
```
index.html            الواجهة الأساسية + شريط التنقل السفلي
manifest.webmanifest  إعدادات التثبيت كتطبيق
sw.js                 Service Worker (كاش للعمل بدون إنترنت)
css/app.css           التنسيق (فاتح/داكن تلقائي، طباعة A4 وحراري)
js/db.js              IndexedDB + tx(): معاملات ذرية (كل عملية تنجح كاملة أو تُلغى كاملة)
js/core.js            تقريب، تحويل الوحدات، شرائح الأسعار
js/services.js        منطق الأعمال: بيع، شراء، مرتجعات، تالف، جرد، دفعات، مصروفات
js/reports.js         صافي الربح، الأكثر مبيعاً/ربحية، نظرة عامة
js/ui.js              نوافذ، توست، قراءة باركود بالكاميرا، طباعة الفواتير
js/pages/*.js         الصفحات: home, products, parties, docs, finance, settings
```

## قاعدة البيانات (Object Stores)
| الجدول | المحتوى |
|---|---|
| products | الاسم، باركود، تصنيف، وحدات، أسعار (تكلفة/جملة/نصف/قطاعي)، شرائح، الكمية (بالوحدة الأساسية)، متوسط التكلفة |
| batches | دفعات الشراء (الكمية المتبقية + تكلفة الوحدة) — أساس FIFO |
| invoices | بيع، شراء، مرتجع مبيعات، مرتجع مشتريات (بنودها وتكلفتها) |
| parties / ledger | العملاء والموردون + كشف حساب لكل طرف |
| cash | حركات الخزنة (وارد/منصرف، مصروفات، دفعات) |
| moves / damages | حركات المخزون + التالف وعجز الجرد |
| settings | بيانات المنشأة، طريقة التكلفة، عدّادات الفواتير |

## كيف تعمل أهم القواعد
- **الوحدات المتعددة:** الكمية تُخزَّن دائماً بأصغر وحدة، وتُعرض تلقائياً (50 قطعة ← 2 كرتونة + 2 قطعة).
- **التكلفة:** من الإعدادات اختر FIFO (حسب الشحنة) أو المتوسط المرجح. كل شراء ينشئ دفعة.
- **التسعير:** سعر العميل حسب مجموعته (جملة/نصف/قطاعي) + شرائح الكمية (مثال: 48=4.5).
- **المرتجع:** السليم يرجع للمخزن بتكلفته الأصلية، والتالف يُسجَّل خسارة. التسوية نقداً أو على حساب الطرف.
- **صافي الربح** = المبيعات − المرتجعات − تكلفة البضاعة المباعة − المصروفات − التالف وعجز الجرد.
- **النسخ الاحتياطي:** البيانات على الجهاز فقط، فصدّر نسخة JSON دورياً من الإعدادات.

## أفكار للمرحلة التالية
مزامنة سحابية اختيارية، صلاحيات مستخدمين (كاشير/مدير)، تواريخ صلاحية للدفعات، أوامر شراء، تصدير Excel.

## سجل الإصلاحات (v2)
- **الصفحة الرئيسية:** إصلاح خطأ `$ is not defined` الذي كان يمنع ظهورها.
- **الخصم:** يُوزَّع على بنود الفاتورة بالتناسب؛ أرباح الأصناف والمرتجعات تحسب بعد الخصم، والمرتجع يردّ المبلغ الصافي فقط.
- **الشراء:** تكلفة الدفعة أصبحت صافية بعد خصم المورد.
- **مرتجع المشتريات:** يُسحب من دفعات نفس الفاتورة ويُعدَّل المتوسط المرجح بتكلفة الشراء الأصلية.
- **الاستيراد:** التحقق من ملف النسخة الاحتياطية قبل مسح أي بيانات.
- **الباركود:** بحث غير حساس لحالة الأحرف ومطابقة تامة أولاً، مع بحث بالتصنيف.
- **أرصدة الموردين/العملاء:** وصف صحيح (عليه/له) في قائمة الفاتورة.
- **حماية:** منع الحفظ المزدوج للفاتورة، وعرض حالة "بدون إنترنت"، وتحسين الكاش (نفس النطاق فقط). رقم الكاش أصبح `wms-v2`.
