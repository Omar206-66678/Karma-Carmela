# كارمه كارميلا — نظام إدارة المخزن والمبيعات (PWA يعمل بدون إنترنت)

تطبيق ويب تقدمي للموبايل والكمبيوتر — بحساب دخول (اسم مستخدم وكلمة سر): يُثبَّت على الشاشة الرئيسية، ويخزّن كل البيانات على الجهاز (IndexedDB)، بدون أي مكتبات خارجية وبدون خطوة بناء — جاهز للرفع مباشرة على **GitHub Pages**.

## النشر على GitHub Pages
1. ارفع محتويات هذا المجلد كما هي (مع الحفاظ على الفولدرات) إلى المستودع.
2. من `Settings → Pages` اختر الفرع والمجلد الجذر.
3. افتح الرابط من الموبايل ثم «إضافة إلى الشاشة الرئيسية».
4. عند تعديل أي ملف: غيّر رقم `V` في `sw.js` (مثلاً `kk-v2`) حتى يتحدّث الكاش.

> قارئ الباركود بالكاميرا يحتاج اتصالاً آمناً (**https**) — وهو متوفر تلقائياً على GitHub Pages، وعلى `localhost` عند التجربة المحلية: `python3 -m http.server 8000`.

```

js/app.js                 الهيدر + القائمة الجانبية + التنقل + الراوتر
js/db.js                  IndexedDB + معاملات ذرية + التحقق من النسخ الاحتياطي
js/core.js                تقريب، وحدات، شرائح أسعار، تفقيط المبالغ بالعربية
js/barcode.js             توليد EAN-13 / EAN-8 / Code128 (SVG قابل للمسح والطباعة)
js/decoder.js             فك الباركود من صورة الكاميرا (يعمل على كل المتصفحات)
js/scanner.js             نافذة المسح: BarcodeDetector + الفك الداخلي + كشاف + مسح مستمر
js/services.js            منطق الأعمال: بيع، شراء، مرتجعات، تالف، جرد، دفعات، أصناف، أطراف
js/reports.js             صافي الربح، مبيعات الأيام، قرب انتهاء الصلاحية
js/ui.js                  الأيقونات، الشعار، الثيم، النوافذ، بناء الفاتورة، الطباعة
js/auth.js                الحساب المحلي: تشفير كلمة السر، القفل، رمز الاسترداد، القفل التلقائي

icons/                    أيقونات التثبيت (192 / 512 / maskable / Apple)
js/pages/*.js             dashboard • products • categories • docs (كاشير/وارد) • invoices • parties • cash • reports • settings
tests/                    اختبارات تُشغَّل بـ node
```

## الاختبارات
```
node tests/barcode.test.mjs     # توليد الباركود وفكّه (ضبابية/ضوضاء/مقلوب/عمودي)
node tests/services.test.mjs    # الخصم، المرتجعات، المتوسط المرجح، الأرصدة، التفقيط
node tests/auth.test.mjs        # الحساب: التشفير، القفل بعد المحاولات، «تذكرني»، الاسترداد
```

## القارئ
- **أصناف / نقطة البيع:** زر الكاميرا داخل صندوق البحث. في الكاشير يوجد أيضاً «مسح مستمر» لإضافة عدة أصناف متتالية.
- يقرأ EAN-13 وUPC-A وEAN-8 وCode128 حتى لو كان الباركود مقلوباً أو عمودياً، ويستخدم `BarcodeDetector` عند توفره لدعم صيغ إضافية (QR وغيرها).
- قارئ الباركود الخارجي (USB/بلوتوث) يكتب في صندوق البحث ثم Enter فيُضاف الصنف مباشرة.
- لتجربة القراءة: افتح صنفاً ← «ملصق باركود» وصوّر الملصق من شاشة جهاز آخر أو من ورقة مطبوعة.

## الخطوط
يُحمَّل خط Cairo من Google Fonts عند وجود إنترنت (ويُحفظ للعمل لاحقاً). بدون إنترنت يُستخدم خط النظام تلقائياً.

## تسجيل الدخول
- أول تشغيل: تُنشئين حساب المدير (اسم مستخدم + كلمة سر)، ثم يظهر **رمز استرداد** مرة واحدة — احفظيه (يُستخدم عند نسيان كلمة السر).
- كلمة السر لا تُخزَّن أبداً؛ يُخزَّن ناتج PBKDF2-SHA256 (150 ألف دورة) مع ملح عشوائي.
- بعد 5 محاولات خاطئة يُقفل الدخول مؤقتاً (30 ثانية ثم يتضاعف حتى 15 دقيقة).
- «تذكرني» يتخطى الدخول 30 يوماً على الجهاز. «القفل التلقائي» (من الإعدادات) يطلب الدخول بعد الخمول.
- الحساب محفوظ منفصلاً عن بيانات المخزن: لا يدخل في النسخة الاحتياطية، ولا يُمسح بـ«مسح كل البيانات».
- **تنبيه صريح:** هذا حماية للدخول على الجهاز نفسه. بيانات المخزن نفسها غير مشفّرة، فاستخدمي قفل شاشة للجهاز. ولكل جهاز بياناته وحسابه (لا توجد مزامنة بين الأجهزة) — صدّري نسخة احتياطية دورياً.

## التثبيت كتطبيق (يعمل بدون إنترنت) مع بقاء الموقع للتحديثات
هو موقع على GitHub Pages **وهو نفسه** التطبيق: كل ما ترفعينه على GitHub يصل للأجهزة المثبّتة تلقائياً عند فتح الإنترنت، ويظهر شريط «تحديث الآن». بدون إنترنت يعمل من النسخة المخزّنة.
- **أندرويد:** Chrome ← القائمة ⋮ ← «تثبيت التطبيق». (أو زر «تثبيت» داخل القائمة الجانبية/الإعدادات).
- **ويندوز / ماك / لينكس:** Chrome أو Edge ← أيقونة التثبيت في شريط العنوان ← «تثبيت». يفتح كبرنامج بنافذته واختصار على سطح المكتب.
- **آيفون:** Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

### ملف APK حقيقي لأندرويد (اختياري)
1. افتحي https://www.pwabuilder.com وأدخلي رابط الموقع ثم Start.
2. اختاري Android ← Generate (يعطيك ملف APK/AAB موقّعاً).
3. التطبيق الناتج يفتح الموقع نفسه، فتبقى التحديثات من GitHub كما هي دون إعادة بناء.
(Windows: PWABuilder يعطي أيضاً حزمة MSIX.)

## سير التحديث
1. عدّلي/استبدلي الملفات على GitHub (مع الحفاظ على الفولدرات).
2. غيّري رقم `V` في `sw.js` (مثلاً `kk-v7`) لتتحدّث النسخة المخزّنة.
3. افتحي التطبيق وأنتِ متصلة: يظهر «يوجد تحديث جديد» ← «تحديث الآن».
